# connect-wireless-adb

Подключение к планшету по «Отладке по Wi-Fi» (Android 11+).

```bash
./connect.sh pair 192.168.1.169:PORT 123456   # один раз: порт и код из диалога
                                              # «Подключить устройство с помощью кода»
eval "$(./connect.sh | tail -1)"              # подключиться и экспортировать ADB_SERIAL
```

Порт подключения меняется после каждой перезагрузки планшета — скрипт находит его
через mDNS. Две грабли, ради которых скрипт и написан:

1. штатный mDNS-бэкенд adb (openscreen) этот планшет **не видит** — скрипт
   перезапускает adb-сервер с `ADB_MDNS_OPENSCREEN=0` (Bonjour macOS видит сразу);
2. после подключения устройство числится **двумя транспортами** (`ip:port` и
   `adb-XXXX._adb-tls-connect._tcp.`), `adb shell` без `-s` отказывает — поэтому все
   скрипты репозитория требуют `ADB_SERIAL`, а `connect.sh` печатает его последней строкой.

Порт сопряжения тоже виден в mDNS (`adb mdns services`, сервис `_adb-tls-pairing`),
пока на планшете открыт диалог с кодом.
